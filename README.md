# 맥스데이 라이프 · 온라인 기도공간 (첫 버전)

캐릭터로 입장해 다른 사람들과 조용히 머물며 기도하고 쉬는 웹 3D 공간입니다.
지도형 입구 마을에서 **맥스데이사 · 맥스데이교회 · 맥스데이성당 · 맥스데이 놀이터 · 맥스데이 카페 · 맥스데이 식당** 중 한 곳을 골라 들어갑니다. 마을 위쪽에는 **자동차 극장**(대형 야외 스크린)이 있습니다.

- 시연 주소: https://whaleguard.github.io/maxday-life/
- 디자인: GPT 주도(디자인 기준 v1.1~v1.3, 벽화·불상·12지신·스테인드글라스·십자고상 이미지 생성) / 구현: Claude

## 화면과 기능

| 공간 | 내용 |
|---|---|
| 입구 지도 | 해 질 무렵 마을. 산 중턱 절(일주문·돌계단·대웅전·범종각·석탑), 언덕 위 교회, 광장의 성당, 공원 놀이터. 건물이나 이름표를 누르면 카메라가 날아가 크게 보여주고 방 목록(인원/정원)에서 골라 입장 |
| 맥스데이사 | 탱화 벽화 + 금동 좌불상 + 광배, 오색 연등, 방석 20석. 앉기 → 합장 · 절하기(4.8초, 반복 선택) · **염주 돌리기(108 카운트)**. 옆 **다도실**(차 마시기), 불교용품 샵, 오늘의 행운 뽑기 기계 |
| 맥스데이교회 | 나무 패널 강단, 빛나는 십자가, 의자 20석, 크리스마스 트리. 기도하기, **성경 말씀 검색**, **찬송 듣기**, 옆 **카페**, 기독교 서점 |
| 맥스데이성당 | 석조 기둥·아치, 스테인드글라스·장미창, 십자고상, 장의자 20석, **봉헌초 24자리(10분 유지, 상대 화면에도 표시)**, 크리스마스 트리, 성가 듣기, 카페, 성물방 |
| 맥스데이 카페 · 식당 | 실사 재질(원목 헤링본 바닥, 벽돌 포인트 벽, 대리석 카운터, 가죽 소파, 통창 밖 거리 풍경)로 만든 실제 매장 구성: 창가·홀·소파·단체석·룸, 셀프바, 화장실, 오픈 주방. **빈자리 보기 → 원하는 자리 예약 → 메뉴 미리 주문**, 예약석 팻말 실시간 표시, 포스 연동용 주문서(JSON) |
| 영상 스크린 | 교회(설교)·성당(미사)·카페·식당 벽 스크린, 마을 자동차 극장. 누르면 유튜브 공식 채널 영상이 재생됨(퍼가기 방식). 거래처별 영상은 `window.MDL_BRAND.videos` 또는 `js/config.js` 의 `VIDEOS` 로 지정 |
| 맥스데이 놀이터 | 운세 기계 6대 · 게임 기계 3대(mapinlife.store 키오스크 프로그램 연결), **랜덤박스 2대**(무료 가상 뽑기 → 머리 소품, 다른 사람에게도 보임), **12지신 석상 마당**(띠별 성격·오늘의 한마디 → 운세향 연결), 어린이 놀이방, 벤치 |

공통: 3인칭 원근 시점(끌어서 둘러보기·휠/핀치 확대), 바닥·빈자리 탭 이동(0.25m 격자 경로탐색), 이름 생성/금칙어, 처음 무음·환경음/공간 음악 음량 분리 저장, 이름 표시 끄기, 동작 줄이기, 저사양 모드, 공덕 포인트(머물기·기도·절·염주·촛불)로 샵 복장(승복·한복·정장·가디건)과 손 소품(염주·목탁·묵주·성경·찬송가·초·연등·연꽃) 구매.

## 실시간 연결 — 완성 여부

| 항목 | 상태 |
|---|---|
| 같은 방 접속자 입장·이동·착석·행동·퇴장 표시 | 완료 (두 브라우저 검증) |
| 같은 좌석 동시 선택 → 한 명만 착석, 나머지는 안내 | 완료 |
| 방 정원 20명 초과 → 같은 공간 다음 방 안내, 방 목록 인원 표시 | 완료 |
| 촛불 점등 상대 화면 반영, 10분 만료, 중복 요청 방지 | 완료 |
| 연결 끊김 → 입력 잠금·안내띠·자동 재연결, 실패 시 재시도/입구로 | 완료 |
| 유령 캐릭터·좌석 정리 (창 닫힘 즉시, 비정상 종료 30초) | 완료 |

연결 방식은 두 가지이며 같은 화면 코드를 씁니다.

1. **공개 MQTT 중계 (현재 GitHub Pages 시연 기본값)** — 서버 없이 동작. 좌석·촛불은 브로커 수신 순서로 판정. 공개 브로커라 운영용으로는 권장하지 않습니다.
2. **자체 방 서버 (운영 권장)** — `server/` 폴더. 서버가 입장·좌석·촛불을 판정합니다.
   ```
   cd server
   npm install
   PORT=8787 node server.js
   ```
   접속: `https://whaleguard.github.io/maxday-life/?server=wss://<도메인>/ws` (또는 `js/config.js` 의 `WS_SERVER` 값 지정)

> 화면의 "· 체험" 캐릭터는 시연용 방문객입니다. 실제 접속자가 아니며 접속 인원에 포함하지 않습니다. 설정에서 끌 수 있습니다.

## 데이터 보관
이름·위치·자세는 접속 중에만 실시간으로 주고받고 저장하지 않습니다(위치 이력 미저장). 촛불 10분 후 소멸. 소품·포인트·음량은 이용자 브라우저에만 저장. 종교 선택 이력 미수집.

## 자산·저작권
- 성경 본문: 성경전서 개역한글판 © 대한성서공회(1961), 저작재산권 만료 본문을 원문 그대로 사용
- 음악: 저작권 만료곡(고요한 밤, 참 반가운 신도여, 저 들 밖에 한밤중에, 나 같은 죄인 살리신, 기뻐하며 경배하세, 만복의 근원 하나님)을 WebAudio 로 직접 합성. 절은 목탁·독경(음성 합성)·범종·풍경
- 이미지: GPT 생성 오리지널(탱화 벽화, 불상, 12지신, 스테인드글라스, 십자고상) — `assets/tex/`
- 3D: 외부 모델 없이 Three.js(0.160.0) 기본 도형으로 제작
- 카페·식당 재질과 창밖 풍경: Poly Haven CC0 텍스처·HDRI (`assets/tex/store_*`)
- 영상: 유튜브 공식 채널 공개 영상을 유튜브 퍼가기 플레이어로 재생(파일 복제 없음). 정식 운영 시 거래처 자체 영상으로 교체 권장
